# GenAI Adoption Program

This project involved designing a gamified adoption program for 1,100 LATAM sellers to drive usage of existing GenAI tooling. The program focused on rewarding activity rather than winning, resulting in over 75% participation within 60 days.

## Key facts
- The program was a gamified adoption programme for 1,100 LATAM sellers. ([[raw/website/projects/genai-adoption-program|website/projects/genai-adoption-program.md › front matter]])
- More than 75% of the 1,100 sellers participated within 60 days. ([[raw/website/projects/genai-adoption-program|website/projects/genai-adoption-program.md › front matter]])
- The productivity case for sellers using GenAI in their daily work was not in dispute. ([[raw/website/projects/genai-adoption-program#1. The tool was never the constraint|website/projects/genai-adoption-program.md › 1. The tool was never the constraint]])
- Mandating GenAI usage produces compliance, not adoption. ([[raw/website/projects/genai-adoption-program#1. The tool was never the constraint|website/projects/genai-adoption-program.md › 1. The tool was never the constraint]])
- The program was partnered with the LATAM sales director and a principal seller. ([[raw/website/projects/genai-adoption-program#2. Why this needed the field, not the analytics team|website/projects/genai-adoption-program.md › 2. Why this needed the field, not the analytics team]])
- Points per qualifying activity makes the behavior countable. ([[raw/website/projects/genai-adoption-program#3. The mechanics, and what each one buys|website/projects/genai-adoption-program.md › 3. The mechanics, and what each one buys]])
- Weekly and monthly ranking cadences were used to keep competition active. ([[raw/website/projects/genai-adoption-program#3. The mechanics, and what each one buys|website/projects/genai-adoption-program.md › 3. The mechanics, and what each one buys]])
- Badges provided a persistent status reward that did not need to be re-bought monthly. ([[raw/website/projects/genai-adoption-program#3. The mechanics, and what each one buys|website/projects/genai-adoption-program.md › 3. The mechanics, and what each one buys]])
- Activity-weighted raffle entries gave everyone a return on participating rather than on winning. ([[raw/website/projects/genai-adoption-program#3. The mechanics, and what each one buys|website/projects/genai-adoption-program.md › 3. The mechanics, and what each one buys]])
- Standings were published provisionally with an explicit window to dispute them before being finalized. ([[raw/website/projects/genai-adoption-program#4. The leaderboard has to be believed|website/projects/genai-adoption-program.md › 4. The leaderboard has to be believed]])
- The program was revised to include country-level standings alongside the regional board. ([[raw/website/projects/genai-adoption-program#5. What changed while it ran|website/projects/genai-adoption-program.md › 5. What changed while it ran]])
- Certifications were added as an earning path, moving the program from rewarding usage to also rewarding capability. ([[raw/website/projects/genai-adoption-program#5. What changed while it ran|website/projects/genai-adoption-program.md › 5. What changed while it ran]])
